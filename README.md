# DecodeLabs UI

A responsive landing page built using HTML, CSS and JavaScript as part of a frontend internship project.

## Features

- Responsive navigation bar
- Hero section
- Feature cards
- About section
- Contact form
- Smooth scrolling
- Contact form validation
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Folder Structure

```
DecodeLabs-UI/
│
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
